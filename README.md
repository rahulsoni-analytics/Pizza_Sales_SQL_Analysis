# # 🍕 Pizza Sales Analysis (SQL | Data Analysis Project)

## 🔍 Project Overview
Performed SQL-based analysis on pizza sales data to extract meaningful insights related to revenue, order trends, and product performance.

Analyzed customer orders, pizza categories, sizes, and sales patterns to support data-driven business decisions.

## 🛠 Tools Used
SQL (MySQL / PostgreSQL)


## 🚀 Skills Demonstrated
- Joins (INNER JOIN, GROUP BY)
- Aggregate Functions (SUM, COUNT, AVG)
- Subqueries
- Data Analysis using SQL

## 📊 Key Analysis Performed
- Total revenue generated from pizza sales
- Total number of orders and quantity sold
- Top-selling pizza types based on revenue
- Most ordered pizza sizes and categories
- Hour-wise and daily order distribution
- Category-wise contribution to total sales

## 📌 Key Insights
- Identified top-performing pizza types contributing maximum revenue
- Found peak order hours to optimize business operations
- Analyzed customer preferences by pizza size and category
- Discovered sales trends to improve inventory planning

## 📂 Project Structure
- `orders.csv` – Order details  
- `pizza_types.csv` – Pizza category information  
- `pizzas.csv` – Pizza pricing and size data  
- SQL Queries for analysis  

## 💡 Conclusion
This project demonstrates the use of SQL for real-world business analysis by extracting actionable insights from raw sales data.
